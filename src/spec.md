# Specification

## Summary
**Goal:** Build a single-page, cute book-aesthetic 1-year anniversary website that prominently celebrates VEERA.

**Planned changes:**
- Create a single-page layout with a cover view that includes “VEERA” prominently and clearly states a 1-year/1st year anniversary message in English.
- Implement a book-inspired navigation flow with a cover and at least 3 inner pages (e.g., Message, Memories, Closing) with Next/Previous controls and responsive, book-like transitions.
- Apply a cohesive warm, cozy theme (cream/tan/soft browns), storybook/handwritten-like typography, consistent components, and readable/accessibile layout (avoid blue/purple as primary colors).
- Add and use static decorative visuals (cover illustration, subtle paper texture background, doodle icons) stored under `frontend/public/assets/generated`.

**User-visible outcome:** Users can open a cute, book-like anniversary page, flip through multiple “pages” with clear controls, and read an English 1-year celebration message featuring VEERA, with consistent cozy styling and decorative visuals.
